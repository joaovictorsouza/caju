# CajuText

Shaping, medida e quebra de linha de texto.

- **Camada:** 1 (dependências só para baixo; ver §5 do plano).
- **Trilha dona:** P-5.
- **Estado:** apenas declarado (M0); sem API pública além do marcador `CajuTextModule`.

- `CajuMath`
- `CajuCollections`
